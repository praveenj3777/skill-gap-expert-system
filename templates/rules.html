Core concepts to explain during academic demonstration and viva examinations:

An expert system separates domain knowledge from computational reasoning. In our project:
  • Knowledge Base: Industry requirements and benchmarks are stored independently in knowledge_base/careers.json.
  • Inference Engine: Reasoning logic in inference_engine.py evaluates formal IF–THEN production rules.
  • Explanation Facility: Traces rule firings so the system can explain why every recommendation was deduced.

Forward Chaining is a data-driven reasoning method. It starts with known input facts asserted in working memory (Student Level = 2, Required Level = 4) and applies production rules forward to derive new facts (Skill Gap = 2, Priority = MEDIUM, Remediation Roadmap) until all conclusions are deduced.

The Explanation Facility maintains an execution audit trace of every rule fired and mathematical comparison. It articulates human-readable rationales: "SQL is marked as a Medium Priority gap because your current level is 2 while required benchmark is 4, which fired RULE-04."
